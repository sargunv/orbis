# Orbis docs

Research and planning for Orbis (working codename), a portable map rendering engine.

- [Decisions](decisions/): significant decisions made during the build

- [Orbis Technical Plan](proposal.html): the architecture and build path, rendered from an earlier revision of [plan.md](plan.md)
- [Engine Anatomy](anatomy.html): how MapLibre Native and MapLibre GL JS work and how they're built
- [Parity Atlas](parity.html): style spec support across the two engines
- [Field Notes](fieldnotes.html): other findings from the codebases, SDKs, issues and PRs

The HTML pages are self-contained; open them directly in a browser.
