# GL JS shaping fixtures

GL JS's shaping tests (`test/integration/symbol-shaping/shaping.test.ts` at
the commit pinned in `xtask/src/fixtures.rs`), with their glyph metrics
replaced by Noto Sans Regular's and their expectations regenerated by GL JS:

- `fontstack-glyphs.json`: upstream's file of the same name, in its format,
  for the same 198 code points, with metrics from OpenFreeMap's Noto Sans
  Regular glyph PBFs (ranges 0–255, 256–511, 19968–20223 and 65024–65279).
  Noto Sans has no U+FE0F, U+1F310 or U+1F5FA; those three copy U+4E09's
  metrics, as upstream's placeholder entries do. Noto Sans is under the SIL
  Open Font License 1.1 (`fonts/OFL.txt`).
- `symbol-shaping/*.json`: the expected `shapeText` results, written by
  `UPDATE=1 npx vitest run --config vitest.config.integration.ts
  test/integration/symbol-shaping` in a GL JS checkout at the pin
  (`npm ci && npm run codegen`) with this `fontstack-glyphs.json` in
  `test/integration/assets/glyphs/`. The test's inline expectations for
  astral characters become x = -36, -12 and 12 with these metrics; every
  other inline expectation is unchanged, and all 19 tests pass.
- License: upstream `LICENSE.txt`, copied as `LICENSE-gl-js.txt` (BSD-3-Clause).

`src/tests.rs` runs the same cases through `orb_text::shape_text` and compares
every field, natively (`cargo test -p orb-text`) and in headless Chrome:

```sh
CARGO_TARGET_WASM32_UNKNOWN_UNKNOWN_RUNNER=wasm-bindgen-test-runner \
  cargo test -p orb-text --lib --target wasm32-unknown-unknown
```

`glyphs/Noto Sans Regular/` holds OpenFreeMap's Noto Sans Regular glyph PBFs
for ranges 0–255 and 65024–65279 (Arabic presentation forms), unchanged from
`https://tiles.openfreemap.org/fonts/Noto Sans Regular/<range>.pbf`, for the
end-to-end PBF test. Noto Sans is under the SIL Open Font License 1.1
(`fonts/OFL.txt`).
